Unexpected Visitors

Unexpected Visitors is an educational game that visualises the functions of white blood cells through character-driven interaction. Players take on the roles of different white blood cells across five levels, combating viruses, bacteria, damaged cells and other threats within a stylised microscopic world.

  • Duration January–May 2022
  • Project Type Educational Game
  • Tools Unity · C# · Visual Studio Code
