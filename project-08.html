Game UI/UX Design · Collaborative Project · 2021

Insomnia

March–June 2021

Collaborator: 宋雪林

This project focuses on game interface design and planning.

Insomnia is a mobile music-driven narrative adventure game with a watercolor silhouette visual style.

Players enter each level after learning about the game’s background and completing the introductory tutorial. At the end of the level, collected fragments are assembled to complete the stage.
